Frikadellen BAF

A headless client for Auction House and Bazaar automation. Buying is one part of it: reconnecting, relisting, watching state and controlling a running session make up the rest.

The loop

BAF listens to the Coflnet flip feed, buys underpriced Auction House BINs on a fast path that pre-clicks Confirm, relists them at target, and claims sold auctions the moment the sale is signalled. In parallel it runs the Bazaar: placing buy and sell orders, tracking fills, collecting, and cancelling stale orders.

The client is built in Rust on Azalea. A real-time web panel and a Discord integration expose state and controls remotely. The repository documentation is the source of truth for current features.

The interesting problems

The happy path is easy. What kept me on this project is everything after it: recovering from a disconnect mid-purchase, tracking an order that fills an hour later, rotating accounts without losing the Coflnet license, and reconstructing what happened overnight from logs instead of guesses.

Current status

As of October 2026 the project README advises against running BAF because of recent ban waves. The source, documentation and releases stay up; the automation itself sits paused.

Automating gameplay violates Hypixel's rules and can lead to account penalties. Flip values in the feed are targets and estimates, not confirmed profit.
