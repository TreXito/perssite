PROJECT NOTE / 01 · ONGOING

Frikadellen
BAF.

A headless Rust client that automates Auction House and Bazaar workflows in Hypixel SkyBlock. It started as a game tool; keeping it observable and usable over time became the more interesting problem.

01 / The idea

From flip feed
to running system.

BAF listens for flip opportunities, buys Auction House items, relists them, and handles Bazaar orders. Those actions are described in the public README. The project is open source, with downloadable builds for Linux, macOS and Windows.

For me, the design question is what happens after the happy path: a connection drops, an order fills late, an account rotates, or I need to understand what the client did while I was away.

02 / System sketch

The work around
the work.

  • Client: a Rust bot built on Azalea acts in game and reconnects when the session changes.
  • Market workflows: Auction House buying and relisting sit alongside Bazaar order tracking and collection.
  • Visibility: the web panel shows state and controls; Discord integration provides remote commands and notifications.
  • Distribution: releases include platform binaries and a loader that checks for a newer build on startup.

The repository documentation is the source of truth for what is currently supported. These notes describe the shape of the project, not a promise of profit or uninterrupted uptime.

04 / Context

A tool with
trade-offs.

It needs a Minecraft Java account and Coflnet for flip data. Results depend on market conditions, connection quality and configuration. Hypixel’s rules also matter: automating gameplay can lead to account penalties. The project README explains the setup and settings in detail.

That context belongs next to the feature list. I would rather show the source and the working interface than a made-up “live” profit counter.
