PROJECT 01 / RUST / HYPIXEL SKYBLOCK

Frikadellen
BAF.

A headless client for Auction House and Bazaar automation. The interesting part is everything around a flip: recovery, relisting, and knowing what the client is doing while it runs.

Explore the project site ↗Read the source ↗

01 / THE WORK

From opportunity to outcome.

BAF listens for Coflnet flip opportunities, buys Auction House items, relists them and handles Bazaar orders. The Rust client is built on Azalea. A web panel and Discord integration make its state and controls visible remotely.

What drew me in was the work after the happy path: reconnecting, tracking an order that fills later, rotating accounts and finding out what happened while I was away.

The repository documentation is the source of truth for current features.

03 / CONTEXT

Read before running.

BAF needs a Minecraft Java account and Coflnet flip data. Automating gameplay can lead to account penalties. As of October 2026, the project README advises against using the software because of recent bans.

Market conditions, connection quality and configuration affect results. I would rather show the source and a real interface than an invented live profit counter.
